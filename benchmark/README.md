# Benchmark

`questions.jsonl`: 20 questions (English, matching the English corpus; use a model that handles the query language).
Generated by `build_questions.py`; verified by `verify_gold.py` (each `evidence_quote` must occur verbatim on `gold_source_id` page `gold_page`, filters must match the gold page's metadata).

- **Split (fixed before any experiment):** q01–q15 dev, q16–q20 test. Test not used to tune strategies.
- **Mix:** direct 11, paraphrase 5, condition 3 (see `type`), metadata_filter 3 (q07, q14 dev; q17 test).
- **Filters:** `document_id` and `function` are known to the user before retrieval and never reveal the answer. q07 needs the filter because MEASURE 1.1 text appears in both documents; q14 uses `function=MANAGE`. Other questions run without filter.
- **`gold_page`:** physical PDF page (1-based); see `printed_page` in `data/pages.jsonl`.
- **q18 caveat:** the source action table interleaves columns, so the quote is truncated at the column break (`…circumvention of safety`). A chunk counts as hit if it contains that quote on the gold page.
- **Multiple valid pages:** not exhaustively searched; a hit on an equivalent passage is accepted only after manual confirmation (GUIDE.md).
- Author wrote questions and labels: single-rater bias.
